# 个人作品集网页 AI Coding 提示词

请在当前项目中实现一个可实际运行的个人作品集网页。视觉参考当前目录中的 `1.png` 与 `2.png`，重点参考 `2.png` 的四段横版连续场景：暗青色神兽体内空间、粉白色记忆能量脉络、微小人物、低饱和雾气和电影级横版构图。不要做成常规官网、卡片墙或逐屏切换的 PPT，而要把整个网页设计成一段从上到下推进、视觉上像角色持续向右探索的小游戏旅程。

页面由四幕组成，但必须看起来属于同一条连续通道：第一幕为封面与“进入记忆”；第二幕为个人简介；第三幕为作品展示；第四幕为技术文档。四幕统一使用相同的角色尺寸、地面高度、镜头视角和主色调，并让一条粉白色发光能量线贯穿所有场景。滚动页面时，角色沿固定路径向右移动，能量线同步点亮；上一幕的洞口、雾气或光流自然延伸到下一幕，不允许硬切、翻页或突然更换构图。

布局采用“信息层 + 游戏层”：桌面端左侧约 35% 作为稳定的文字安全区，只保留暗色雾气、渐变和少量粒子，确保标题、正文、标签和按钮清晰可读；右侧约 65% 展示角色、神兽遗迹和交互主体。背景不能铺满高频细节，降低约 50% 的装饰密度；每幕只保留一个视觉焦点。封面焦点为沉睡神兽，简介焦点为一面记忆水镜，作品区焦点为 3 个可交互心核，文档区焦点为一条神经主干与 3 个知识节点。

交互需要克制、丝滑、有游戏感：滚轮与触控驱动场景推进；角色移动带轻微惯性；前景、中景、远景产生不同速度的视差；能量线有流动粒子与呼吸亮度；标题和正文在角色接近节点时淡入并轻微上移；离开时淡出；作品心核悬停时亮起并显示项目摘要，点击后打开沉浸式详情层，关闭后回到原探索位置；技术节点分别呈现 Shader、Niagara、实时渲染或技术文章。所有动画优先使用 transform 与 opacity，保持 60fps，并支持 `prefers-reduced-motion`。

视觉规范：全屏 16:9 氛围，背景以深蓝黑、暗青、灰蓝为主，强调色使用低饱和粉白与少量冰蓝；字体使用有东方奇幻气质的中文标题字体搭配高可读无衬线正文；文字区域增加局部暗色渐变和轻微背景模糊，但不要使用明显矩形卡片。按钮表现为符文、光点或路径节点，不使用常规大色块按钮。加入体积雾、微尘、柔和 Bloom、能量脉冲和非常轻微的环境漂移，避免高饱和霓虹、赛博朋克、复杂 HUD、顶部传统导航栏、上下黑边和 AI 乱码。

请先检查项目现有技术栈与目录结构，在不破坏原有配置的前提下实现。优先复用当前依赖；若项目为空，可使用 React + TypeScript + Vite，样式使用 CSS Modules 或项目已有方案，动画优先 GSAP ScrollTrigger 或 Framer Motion，复杂背景可使用分层图片与 CSS/Canvas 粒子，不要为了效果引入笨重的 3D 引擎。将场景、角色、能量线、内容数据与动画控制拆分为可维护组件，内容由配置数据驱动，方便后续替换姓名、简介、作品、文档和联系方式。

必须完成：响应式桌面与移动端布局；桌面端保持横版探索构图，移动端改为纵向叙事但保留能量线和节点关系；图片懒加载与尺寸预留；可访问性标签；键盘可操作；首屏加载状态；无素材时提供可替换占位层。最终交付完整可运行页面，并说明关键文件、启动命令以及替换视觉素材和个人内容的位置。
