# 2026-07-25 工作日志

## 个人作品集网站 - 基础版本搭建

- 使用 React + Vite 从零搭建技术美术个人作品集网站
- 技术栈：React 18 + Vite 8 + Framer Motion + Lucide Icons
- 实现了以下模块：
  - **Navbar**: 固定顶部导航，滚动时毛玻璃效果，移动端汉堡菜单
  - **Hero**: 全屏首页，支持视频背景（带降级），大字标题动画，渐变文字效果
  - **About**: 个人经历模块，头像占位、技能标签、数据统计（5+年经验等）
  - **Projects**: 精选项目网格，标签筛选系统（UE5/渲染/VFX/Shader/程序化/工具/材质），点击弹出详情模态框
  - **ProjectModal**: 项目详情弹窗，支持视频/动图/对比拖动图/图片/代码块多种媒体类型
  - **Footer**: 整屏收尾页，大标题 + 联系方式 + 社交媒体链接
- 设计：暗色系、1700px 版心、克制高级风格
- 数据配置集中在 src/data.js，方便后续修改
- 开发服务器运行在 localhost:3000
